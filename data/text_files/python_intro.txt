Core Features
Readable Syntax: Python uses significant indentation to define code blocks, making it highly readable compared to languages that use braces or keywords.
Interpreted Language: Code is executed line-by-line as soon as it is written, allowing for quick prototyping.
Dynamically Typed: You don't need to declare variable types (like int or string) explicitly; the interpreter detects them at runtime.
Extensive Libraries: Known for its "batteries-included" philosophy, Python has a massive standard library and third-party packages for almost any task.

Basic Building Blocks
Variables: Used to store data in memory. You assign values using the = operator (e.g., x = 5).
Data Types: Includes integers (numbers), strings (text), booleans (True/False), and collection types like lists and dictionaries.
Functions: Reusable blocks of code defined with the def keyword to perform specific actions.
Control Flow: Uses if/else statements for decision-making and for/while loops for repetitive tasks.
